Un tour, un pas

Vous avancez d'une case, puis les cônes tournent d'un quart de tour. Si le vôtre s'allume, vous êtes vu.

La flèche dit où regarde un veilleur, le petit rond dans quel sens il tourne. Attendre est un coup comme un autre.

Chaque plan est vérifié résoluble avant de vous être servi, et le nombre minimal de tours est affiché.
